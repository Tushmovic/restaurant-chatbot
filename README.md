# Restaurant ChatBot

A restaurant ordering chatbot that assists customers in placing orders for their preferred meals. Built with React frontend and Node.js/Express backend.

## Features

- 🍽️ **Menu Browsing**: Browse restaurant menu with number-based selection
- 🛒 **Order Management**: Add items, view current order, checkout
- 💳 **Payment Integration**: Paystack payment gateway integration
- 📜 **Order History**: View past orders
- ❌ **Order Cancellation**: Cancel pending orders
- 🔄 **Session Management**: Device-based session tracking
- 📱 **Responsive Design**: Works on mobile and desktop

## Tech Stack

**Frontend:**
- React 18
- Tailwind CSS
- Axios for API calls
- React Icons

**Backend:**
- Node.js with Express
- MongoDB with Mongoose
- Express Session for session management
- Paystack API for payments
