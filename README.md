# Restaurant ChatBot 🍽️🤖

A restaurant ordering chatbot that assists customers in placing orders for their preferred meals using a number-based menu system.

## 🚀 Live Demo
- **Live Application:** [https://restaurant-chatbot-thmj.onrender.com](https://restaurant-chatbot-thmj.onrender.com)
- **Backend API:** [https://restaurant-chatbot-thmj.onrender.com/api](https://restaurant-chatbot-thmj.onrender.com/api)

## 📋 Features
- ✅ Chat interface with number-based navigation
- ✅ Device-based session management
- ✅ Menu browsing and item selection (1-10)
- ✅ Order placement and checkout
- ✅ Paystack payment integration
- ✅ Order history viewing
- ✅ Order cancellation
- ✅ Input validation

## 🛠️ Tech Stack
- **Backend:** Node.js, Express, MongoDB, Mongoose
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Payment:** Paystack API
- **Deployment:** Render
